**Simple Sample Spaces:** A finite sample space ( S ) is a simple finite sample space if all the outcomes are equally likely, i.e., ( p_i = \frac{1}{n} ) for all ( i = 1 : n ). In this case an event ( A ) that contains ( m ) outcomes will have probability  
[  
Pr(A) = \frac{m}{n}.  
]  
Note that this require us to count. First we need to count the elements in the sample space ( S ) and then count the elements in ( A ).
