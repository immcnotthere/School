# Conditional PMF

For discrete $X,Y$, $f_{X\mid Y}(x\mid y)=f_{X,Y}(x,y)/f_Y(y)$ when $f_Y(y)>0$; it is itself a valid pmf in $x$ for each fixed $y$.
