# Linear Transformation Property of the Normal Distribution

If $X\sim Normal(\mu,\sigma^2)$ and $Y=aX+b$ with $a>0$, then $Y\sim Normal(a\mu+b,a^2\sigma^2)$: a linear transform of a Normal stays Normal.
