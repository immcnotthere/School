## Page 1–2 — What is a 2nd Order Linear ODE?

### General 2nd Order ODE

$$y'' = f(t,\, y,\, y')$$

### Definition: Linear

The ODE is **linear** if it can be written as:

$$a(t)\,y'' + b(t)\,y' + c(t)\,y = f(t)$$

> The equation is linear **in** $y''$, $y'$, and $y$ — coefficients $a, b, c$ may depend on $t$ but not on $y$.


#### 📝 Notes
>Recall [[Linearity]] Is a property of a set preserving certain features over set defining operations and not being affine

## Page 3–4 — Examples

### Example 1: Undamped Pendulum (Nonlinear)
Picture the equation $\frac{d^2\theta}{dt^2} = -\frac{g}{L} \sin \theta$ describes how the angle of a pendulum changes over time.

We anatomize the pendulum's movement into the following components

A. They should all be vector Components at Point $M$

Gravity pulls straight down, but the pendulum is constrained to move in a circular arc. We split the weight $mg$ (mass and gravity) into two perpendicular components based on the angle $\theta$:

- **Downward (Gravity):**
    
    $$\vec{F}_g = mg$$
    
- **Toward the Hashed Line (Restoring Force):**
    
    $$F_{\text{tangential}} = -mg \sin \theta$$
    
- **Along the Rod (Radial Force):**
    
    $$F_{\text{radial}} = mg \cos \theta$$

- Describes the motion of an undamped pendulum
- **Nonlinear** because of the $\sin\theta$ term...
	- The sine function is non-linear because it violates the principles of superposition (additivity and homogeneity), meaning $\sin(a+b) \neq \sin(a) + \sin(b)$
	- Simply put the output does not change proportionally to the input

### Example 2: Spring-Mass-Dashpot System (Linear)

$$m\,y'' + c\,y' + k\,y = f(t)$$

| Term | Meaning |
|------|---------|
| $m$ | Mass |
| $c\,y'$ | Dashpot (resists motion, $F = -c\dot{y}$) |
| $k\,y$ | Spring force (restoring, $F = -ky$) |
| $f(t)$ | External forcing |
| $y(t)$ | Displacement from equilibrium |

This is the canonical [[Spring-Mass-Dashpot]] system — **linear**.

### 📝 Notes
> The significance of this is roughly that we can observe Real phenomenon That can be described in the linear equation which as linear algebra tests provide several benefits in computation and analysis

## Page 4–6 — Existence and Uniqueness: General Case

### Theorem (General Case)
We don't like to go searching for solutions that don't exist so we make sure we know it exists and that if, ideally, its unique. 

This looks very similar to the first order general equation [[First Order General Equation Theorem]].

Only now the function takes of 2nd order ~ y'' is equal to x,y,y'.
Equivalently...

For a second-order ordinary differential equation, the function $f$ defines the [[acceleration]] based on the independent variable, the [[position]], and the [[Velocity]]:

$$y'' = f(x, y, y')$$

Technical Components:

- **$y''$**: The second derivative (acceleration).
    
- **$x$**: The independent variable (often time $t$).
    
- **$y$**: The dependent variable (position).
    
- **$y'$**: The first derivative (velocity).
---
If $f(t, u, w)$ is **well-behaved** ([[Continuity|continuous]] (no jumps, holes, or blowups) + [[Existence_and_Uniqueness_Theorem#Lipschitz Condition|Lipschitz condition]]
(See derivative of sqrt for failure example)


So there must exist three continuous variables in $\mathbb{R}^3$ in an open box in $x$ containing the arbitrary points $(x_0, y_0, y_0')$, then there exists a unique solution defined around x for the function and it's derivative permitting the writing of the IVP:

$$y'' = f(x,\, y,\, y'), \qquad y(t_0) = y_0,\quad y'(t_0) = y_0'$$

has a **unique solution** defined on some interval $(t_0 - \delta,\, t_0 + \delta)$ around $t_0$.

>Simply put, ***given your starting position, there is exactly one path the math allows, and we can guarantee that path stays true for at least a small window of time around your start*** supposing the above conditions are fulfilled

interestingly to prove this we need to split the equation into two first order ODEs

but first it's notation in standard form

---
Reduction to Standard Form

For the linear equation $a(t)y'' + b(t)y' + c(t)y = f(t)$, we can break this equation quite nicely into to two 1st order ODEs by dividing by $a(t)$ wherever $a(t) \neq 0$ bc a(t) makes this a first order equation. So if a is not 0, we can divide by it so... 

$$a(t)y'' + b(t)y' + c(t)y = f(t)$$
becomes...
$$y'' + p(t)\,y' + q(t)\,y = h(t)$$

where:

$$p = \frac{b}{a}, \qquad q = \frac{c}{a}, \qquad h = \frac{f}{a}$$

> The equation "makes sense" as a 2nd order ODE on intervals where $a(t) \neq 0$.

#### 📝 Notes
>So now the equation for the linear case makes it look a lot like the 1st order case but with this extra term

Theorem (Linear Case) ⭐

If $p(t)$, $q(t)$, and $f(t)$ (the [[Forcing Function]]) are **continuous** on an interval $(a, b)$ and $t_0 \in (a, b)$ (this is to say it can be on any point on the interval, all we need are those three functions to be continuous)


Then if we are given the initial values: $\qquad y(t_0) = y_0,\quad y'(t_0) = y_1$

Then we can write the linear case of the IVP as:

$$y'' + p(t)\,y' + q(t)\,y = f(t), \qquad y(t_0) = y_0,\quad y'(t_0) = y_1$$

has a **unique solution defined on all of $(a, b)$** for any $y_0, y_1 \in \mathbb{R}$.

> **Key upgrade over the general case:** the solution exists on the *entire* interval $(a,b)$, not just locally around $t_0$.

### 📝 Notes
>here's an example which demonstrates the difference between them
- Why the Linear Case Is a Massive Upgrade
			- To understand the difference between the general and linear existence theorems, think of it as the difference between a **flashlight** that shows you two feet ahead versus a **map** of the entire highway.
	- The General Case: The "Local" Trap
		- The general theorem is cautious — it only guarantees a solution exists in a tiny bubble $(t_0 - \delta, t_0 + \delta)$ around your starting point. It cannot warn you about a "cliff" ahead.
			- **Example:** $y' = y^2$, $\quad y(0) = 1$
				  - **Step 1 — Separate variables**
				    - $\dfrac{dy}{y^2} = dt$
				  - **Step 2 — Integrate both sides**
				    - $\int y^{-2}\,dy = \int dt \implies -\dfrac{1}{y} = t + C$
				  - **Step 3 — Apply initial condition $y(0) = 1$**
				    - $-\dfrac{1}{1} = 0 + C \implies C = -1$
				  - **Step 4 — Solve for $y$**
				    - $-\dfrac{1}{y} = t - 1 \implies y(t) = \dfrac{1}{1-t}$
				  - **Step 5 — Where it breaks**
				    - At $t = 1$: the denominator $1 - t = 0$, so $y(1) \to \infty$
				    - The general theorem only promised a solution near $t_0 = 0$ — it said nothing about $t = 1$
				    - The cliff was always there; the theorem just couldn't see it
				- Here $f(t, y) = y^2$ is smooth, continuous, and Lipschitz near the start. The theorem says: *"You are safe for a little bit of time around zero."*
			- The actual solution is: $y(t) = \frac{1}{1 - t}$
		- Even though $y^2$ looks fine everywhere, the solution hits a **vertical wall at $t = 1$**. The general theorem hid this explosion — it only promised safety for a split second and could not tell us the system would break just one second into the future.
	- The Linear Case: The "Global" Map
		- For a linear equation $y' + p(t)y = g(t)$, if $p$ and $g$ are continuous on $(a, b)$, the solution is guaranteed to exist on the **entire interval** — no surprises.
			- **Example:** $y' = y$, $\quad y(0) = 1$
		- Here $p(t) = -1$ and $g(t) = 0$, both continuous on $(-\infty, \infty)$. The theorem promises the solution exists for **all time**.
		- The actual solution is: $y(t) = e^t$
			- No cliffs, no blow-up, no hidden expiration date. Because the equation is linear, the solution cannot suddenly decide to explode as long as the coefficients stay well-behaved. The math gives you the **full story** from the start.
		-  **Worked example: linear case**
				  - ODE: $y' = y$, $\quad y(0) = 1$
				  - Rewrite as $y' - y = 0$, so $p(t) = -1$ and $h(t) = 0$ — both continuous on $(-\infty, \infty)$
				  - The linear E&U theorem immediately guarantees a solution on all of $\mathbb{R}$, before solving
				  - **Step 1 — Separate variables**
				    - $\dfrac{dy}{y} = dt$
				  - **Step 2 — Integrate both sides**
				    - $\int \dfrac{dy}{y} = \int dt \implies \ln|y| = t + C$
				  - **Step 3 — Exponentiate**
				    - $y = A e^t \quad (A = \pm e^C)$
				  - **Step 4 — Apply initial condition $y(0) = 1$**
				    - $A \cdot e^0 = 1 \implies A = 1$
				  - **Step 5 — Final solution**
				    - $y(t) = e^t$
				    - Defined and smooth on $(-\infty, \infty)$ — no cliffs, no blow-up, no expiration date
	- **Side by side**
	  - General $y' = y^2$: solution $\dfrac{1}{1-t}$, blows up at $t = 1$, theorem only promises a local bubble, singularity hidden
	  - Linear $y' = y$: solution $e^t$, never blows up, theorem promises all of $(a,b)$, full story visible from the start

---

### Side-by-Side

| Feature | General Case $y' = f(t,y)$ | Linear Case $y' + py = g$ |
|---------|---------------------------|--------------------------|
| Existence | **Local** — only near $t_0$ | **Global** — all of $(a, b)$ |
| Predictability | Could hit a singularity anytime | Safe as long as coefficients are continuous |
| What it reveals | Hides the system's expiration date | Reveals the entire lifespan |

> **The takeaway:** In the general case you are flying blind. In the linear case you have the full blueprints. Linearity acts as a structural guarantee — the solution will be as stable and long-lasting as the forces driving it.

## Page 8–9 — The [[Superposition Principle]]

### Theorem ⭐

If $y_1$ and $y_2$ are solutions of:

$$y'' + p(t)\,y' + q(t)\,y = 0 \tag{$\star$}$$

on $(a, b)$, then $c_1 y_1 + c_2 y_2$ is also a solution of $(\star)$ on $(a, b)$ for **any** scalars $c_1, c_2 \in \mathbb{R}$
via. the [[Superposition Principle|superposition]] principle which states
**Whenever a system is governed by a linear rule, its responses to multiple inputs can be computed separately and then added.**

- Matrix demonstration
	  - Let $A = \begin{pmatrix} 1 & -1 \\ -1 & 1 \end{pmatrix}$
		  - Two solutions of $A\mathbf{x} = \mathbf{0}$
		    - $A\begin{pmatrix}1\\1\end{pmatrix} = \begin{pmatrix}0\\0\end{pmatrix}$
		    - $A\begin{pmatrix}3\\3\end{pmatrix} = \begin{pmatrix}0\\0\end{pmatrix}$
		  - Their linear combination is also a solution
		    - $c_1\begin{pmatrix}1\\1\end{pmatrix} + c_2\begin{pmatrix}3\\3\end{pmatrix} = \begin{pmatrix}c_1+3c_2\\c_1+3c_2\end{pmatrix}$
		    - $A\begin{pmatrix}c_1+3c_2\\c_1+3c_2\end{pmatrix} = \begin{pmatrix}0\\0\end{pmatrix}$
		  - The null space is $\left\{t\begin{pmatrix}1\\1\end{pmatrix}: t \in \mathbb{R}\right\}$ — a 1-dimensional vector space
	- Superposition of inputs
	  - $A\begin{pmatrix}1\\0\end{pmatrix} = \begin{pmatrix}1\\-1\end{pmatrix} = \mathbf{b}_1$
	  - $A\begin{pmatrix}2\\0\end{pmatrix} = \begin{pmatrix}2\\-2\end{pmatrix} = \mathbf{b}_2$
	  - Want the solution for $3\mathbf{b}_1 + \mathbf{b}_2 = \begin{pmatrix}5\\-5\end{pmatrix}$
	    - Answer is just $3\begin{pmatrix}1\\0\end{pmatrix} + \begin{pmatrix}2\\0\end{pmatrix} = \begin{pmatrix}5\\0\end{pmatrix}$
	    - $A\begin{pmatrix}5\\0\end{pmatrix} = \begin{pmatrix}5\\-5\end{pmatrix}$
	  - No new solve needed — assembled from pieces already computed
### Proof Sketch
- Proof that $\tilde{y} = c_1y_1 + c_2y_2$ solves $y'' + py' + qy = 0$
  - Differentiate the combination
    - $y' = c_1y_1' + c_2y_2'$
    - $y'' = c_1y_1'' + c_2y_2''$
  - Substitute into the ODE
    - $y'' + py' + qy = (c_1y_1'' + c_2y_2'') + p(c_1y_1' + c_2y_2') + q(c_1y_1 + c_2y_2)$
  - Collect by $c_1$ and $c_2$
    - $= c_1(y_1'' + py_1' + qy_1) + c_2(y_2'' + py_2' + qy_2)$
  - Each bracket is zero because $y_1$ and $y_2$ are solutions
    - $= c_1 \cdot 0 + c_2 \cdot 0 = 0$ $\checkmark$


Let $\tilde{y} = c_1 y_1 + c_2 y_2$. Then:

$$\tilde{y}'' + p\tilde{y}' + q\tilde{y} = c_1\underbrace{(y_1'' + py_1' + qy_1)}_{=\,0} + c_2\underbrace{(y_2'' + py_2' + qy_2)}_{=\,0} = 0 \checkmark$$

### 📝 Notes!!
>Interestingly this is because differentiation is a linear transformation.
>	If we dif a sum of two functions, you get the sum of the derivatives
>	dif a constant multiple of a function, you get a constant multiple of the derivative

## Page 10 — Solution Space is a Vector Space

### Conclusion 1

The set of solutions of $y'' + py' + qy = 0$ on $(a,b)$ is a **[[Vector space]]**, because:

1. **Not empty:** $y = 0$ is always a solution
2. **Closed under addition and scalar multiplication** (by the [[Superposition Principle]])

> **Natural question:** Can we find a *basis* for this solution space?

## Pages 11–15 — Worked Example: $y'' + 4y' + 4y = 0$

### Two Solutions

$$y_1 = e^{-2t}, \qquad y_2 = t\,e^{-2t}$$

**Verification of $y_1$:**

$$y_1' = -2e^{-2t}, \quad y_1'' = 4e^{-2t}$$
$$4e^{-2t} + 4(-2e^{-2t}) + 4e^{-2t} = 0 \checkmark$$

**Verification of $y_2$:**

$$y_2' = e^{-2t} - 2te^{-2t}, \quad y_2'' = -4e^{-2t} + 4te^{-2t}$$
$$(-4e^{-2t} + 4te^{-2t}) + 4(e^{-2t} - 2te^{-2t}) + 4te^{-2t} = 0 \checkmark$$

### Solving the IVP: $y(0) = a,\ y'(0) = b$

Want $c_1, c_2$ such that $y = c_1 e^{-2t} + c_2 t e^{-2t}$ satisfies the initial conditions.

At $t = 0$:

$$c_1 e^0 + c_2 \cdot 0 \cdot e^0 = a \implies c_1 = a$$

Differentiating and evaluating at $t = 0$:

$$-2c_1 + c_2 = b \implies c_2 = 2a + b$$

### General Solution

$$y = a\,e^{-2t} + (2a + b)\,t\,e^{-2t}$$

By uniqueness, this is the **unique** solution — so:

$$\text{Span}\{e^{-2t},\, te^{-2t}\} = \text{all solutions}$$

## Page 16–17 — Linear Independence of $y_1, y_2$

$\{e^{-2t},\, te^{-2t}\}$ is a **basis** because these solutions are **linearly independent**:

Suppose $c_1 e^{-2t} + c_2 t e^{-2t} = 0$ for all $t$. Then:

- At $t = 0$: $c_1 = 0$
- At $t = 1$: $c_2 e^{-2} = 0 \implies c_2 = 0$

So the only solution is $c_1 = c_2 = 0$. ✓

## Pages 17–20 — [[Fundamental Solutions]]: General Theory ⭐

### Theorem

If $p(t)$ and $q(t)$ are continuous on $(a, b)$, then there exists a pair of solutions $y_1, y_2$ of:

$$y'' + p(t)\,y' + q(t)\,y = 0 \tag{$\star$}$$

such that **every other solution** has a **unique representation**:

$$y = c_1 y_1 + c_2 y_2$$

### Construction (Proof)

Choose any $t_0 \in (a, b)$. By the existence theorem:

- $\exists!\, y_1$ solving $(\star)$ with $y_1(t_0) = 1,\quad y_1'(t_0) = 0$
- $\exists!\, y_2$ solving $(\star)$ with $y_2(t_0) = 0,\quad y_2'(t_0) = 1$

For any solution $y$ of $(\star)$, set $\tilde{y} = y(t_0)\cdot y_1 + y'(t_0)\cdot y_2$. Then:

$$\tilde{y}(t_0) = y(t_0), \qquad \tilde{y}'(t_0) = y'(t_0)$$

By uniqueness: $y = \tilde{y} = y(t_0)\,y_1 + y'(t_0)\,y_2$. ✓

### 📝 Notes
>

## Page 20–21 — [[Fundamental Solutions]]: Terminology

### Definition

$y_1$ and $y_2$ form a **fundamental pair of solutions** (or **[[Fundamental Set of Solutions]]**) of $(\star)$ if they are:
1. Both solutions of $(\star)$
2. **Linearly independent**

### General Solution

$$\boxed{y_h = c_1 y_1 + c_2 y_2}$$

is called the **general solution** of $(\star)$.

> Note: $y_1$ and $y_2$ constructed above (with identity-matrix initial conditions at $t_0$) are automatically linearly independent — *exercise*.

## Page 21–22 — The [[Wronskian]]

### Definition

For two differentiable functions $y_1(t)$ and $y_2(t)$, the **[[Wronskian]]** is:

$$W(y_1, y_2)(t) = \begin{vmatrix} y_1(t) & y_2(t) \\ y_1'(t) & y_2'(t) \end{vmatrix} = y_1(t)\,y_2'(t) - y_1'(t)\,y_2(t)$$

## Page 22–25 — Wronskian Criterion for Fundamental Pairs ⭐

### Claim

If $y_1, y_2$ are solutions of $y'' + py' + qy = 0$ on $(a, b)$, then they form a **fundamental pair** if and only if:

$$W(y_1, y_2)(t_0) \neq 0 \quad \text{for some } t_0 \in (a,b)$$

### Proof ($\Rightarrow$ direction)

Suppose $W(y_1, y_2)(t_0) \neq 0$. Let $y_3$ be any solution with $y_3(t_0) = u_0$, $y_3'(t_0) = v_0$. The system:

$$\begin{bmatrix} y_1(t_0) & y_2(t_0) \\ y_1'(t_0) & y_2'(t_0) \end{bmatrix} \begin{bmatrix} c_1 \\ c_2 \end{bmatrix} = \begin{bmatrix} u_0 \\ v_0 \end{bmatrix}$$

has a **unique solution** $(c_1, c_2)$ because the coefficient matrix has nonzero determinant $= W(y_1, y_2)(t_0) \neq 0$.

Then $\tilde{y} = c_1 y_1 + c_2 y_2$ and $y_3$ are both solutions of $(\star)$ with the same value and derivative at $t_0$. By uniqueness: $y_3 = \tilde{y}$.

### Proof ($\Leftarrow$ direction — Exercise)

Suppose $y_1, y_2$ form a fundamental pair. Let $y$ solve $(\star)$ with $y(t_0) = 0$, $y'(t_0) = 1$. Then $y = c_1 y_1 + c_2 y_2$... show $W(y_1, y_2)(t_0) \neq 0$.

## Pages 26–30 — Abel's Theorem: Wronskian Satisfies a 1st Order ODE ⭐

### Observation

If $y_1, y_2$ are solutions of $y'' + py' + qy = 0$ on $(a,b)$, then $W = W(y_1, y_2)$ satisfies:

$$W' + p(t)\,W = 0 \quad \text{on } (a,b)$$

### Proof

Compute $W'$:

$$W = y_1 y_2' - y_1' y_2$$
$$W' = y_1 y_2'' + \cancel{y_1' y_2'} - y_1'' y_2 - \cancel{y_1' y_2'} = y_1 y_2'' - y_1'' y_2$$

Substitute the ODE: $y_i'' = -py_i' - qy_i$:

$$W' = y_1(-py_2' - qy_2) - (-py_1' - qy_1)y_2$$
$$= -p(y_1 y_2' - y_1' y_2) - q\cancel{(y_1 y_2 - y_1 y_2)}$$
$$= -pW$$

So $W' + pW = 0$. ✓

### Abel's Formula ⭐

Solving $W' + p(t)W = 0$ (separable first-order ODE):

$$\boxed{W(y_1, y_2)(t) = C\,\exp\!\left(-\int_{t_0}^{t} p(s)\,ds\right)}$$

for some constant $C$ depending on the choice of $y_1, y_2$.

### Conclusion: Wronskian is Either Always Zero or Never Zero

If $y_1, y_2$ are solutions of $(\star)$ on $(a, b)$, then **exactly one** of the following holds:

$$W(y_1, y_2)(t) \neq 0 \quad \text{for all } t \in (a,b)$$
$$W(y_1, y_2)(t) = 0 \quad \text{for all } t \in (a,b)$$

> This follows immediately from Abel's formula: $W(t) = Ce^{-\int p\,ds}$, and the exponential is never zero. So $W \equiv 0 \iff C = 0$, and $W \neq 0$ everywhere $\iff C \neq 0$.

## Key Theorems Summary

| Result | Statement |
|--------|-----------|
| **E&U (Linear)** | If $p, q, f$ continuous on $(a,b)$, IVP has unique solution on all of $(a,b)$ |
| **[[Superposition Principle]]** | Any linear combination of solutions of $(\star)$ is a solution |
| **Fundamental Pair Existence** | There always exist two linearly independent solutions $y_1, y_2$ spanning all solutions |
| **Wronskian Criterion** | $y_1, y_2$ form a fundamental pair $\iff W(y_1,y_2)(t_0) \neq 0$ for some $t_0$ |
| **[[Abels Formula|Abel's Formula]]** | $W(t) = C\exp\!\left(-\int_{t_0}^t p\,ds\right)$ — Wronskian is either always $0$ or never $0$ |

## Key Equations

$$a(t)y'' + b(t)y' + c(t)y = f(t) \quad \text{(general linear 2nd order ODE)}$$

$$y'' + p(t)y' + q(t)y = 0 \tag{$\star$ homogeneous}$$

$$W(y_1, y_2)(t) = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} = y_1 y_2' - y_1' y_2$$

$$y_h = c_1 y_1 + c_2 y_2 \quad \text{(general solution)}$$

$$W' + p(t)W = 0 \implies W(t) = C\,e^{-\int p\,dt} \quad \text{(Abel's formula)}$$
