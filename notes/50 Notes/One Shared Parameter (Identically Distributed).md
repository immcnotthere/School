# One Shared Parameter (Identically Distributed)

The second half of i.i.d.: every trial uses the same parameter value. Different results are expected from randomness; a different parameter needs a stated reason (rush hour, fatigue, changed conditions). Separate from independence.

Example: calls 3, 5, 2, 4 come from one λ; free-throw exhaustion over 100 shots would break it.
