## Motivational Example I

%%
The professor opens with this to show exactly where all previous methods break down. Undetermined coefficients requires f(t) to be a nice function. Variation of parameters would work in principle but becomes extremely tedious when f(t) has multiple jump discontinuities requiring the solution to be stitched together across intervals. The Laplace transform handles the whole thing at once.
%%

Solve:

$$y'' + 2y' + 5y = f(t), \qquad y(0) = 0,\; y'(0) = 0$$

where:

$$f(t) = \begin{cases} 1 & 0 < t < 1 \\ 0 & 1 \leq t < 2 \\ 1 & 2 < t < 3 \\ 0 & 3 \leq t \end{cases}$$

**The problem:** $f$ is discontinuous at $t = 1, 2, 3$. No single guess form works for the whole interval.

### Approach 1 — Stitching Together (the hard way)

Break into four sub-IVPs, each on one interval, matching position and velocity at each junction:

| Interval | ODE | Initial conditions | Solution |
|---|---|---|---|
| $0 < t < 1$ | $y'' + 2y' + 5y = 1$ | $y(0)=0$, $y'(0)=0$ | $y_1(t)$ |
| $1 \leq t < 2$ | $y'' + 2y' + 5y = 0$ | $y(1)=y_1(1)$, $y'(1)=y_1'(1)$ | $y_2(t)$ |
| $2 \leq t < 3$ | $y'' + 2y' + 5y = 1$ | $y(2)=y_2(2)$, $y'(2)=y_2'(2)$ | $y_3(t)$ |
| $3 \leq t$ | $y'' + 2y' + 5y = 0$ | $y(3)=y_3(3)$, $y'(3)=y_3'(3)$ | $y_4(t)$ |

**Homogeneous solution** (used repeatedly):

$$y_h = e^{-t}(c_1\cos 2t + c_2\sin 2t)$$

Working through the matching at each junction gives approximate numerical values. The solution across all four pieces is glued together — it works, but it is laborious.

**What about:**

$$y'' + 2y' + 5y = g(t), \qquad g(t) = t - n \text{ for } n \leq t < n+1, \quad n = 0,1,2,\ldots$$

This is an infinite sawtooth. The stitching approach requires infinitely many sub-problems. A new method is needed.

---

## The Laplace Transform — Definition

> [!definition] Laplace Transform
> For a function $f(t)$ defined for $t \geq 0$:
> $$\mathcal{L}\{f(t)\} = F(s) = \int_0^\infty f(t)e^{-st}\,dt = \lim_{T\to\infty}\int_0^T f(t)e^{-st}\,dt$$
> provided the limit exists for some $s = s_0$.

The **parameter** is $s$. The **variable** in the output $F(s)$ is $s$. Time $t$ is integrated out — it disappears.

---

## Worked Examples of the Transform

### Example 1 — $\mathcal{L}\{1\}$

$$\mathcal{L}\{1\} = \int_0^\infty 1\cdot e^{-st}\,dt = \lim_{T\to\infty}\int_0^T e^{-st}\,dt = \lim_{T\to\infty}\left[-\frac{1}{s}e^{-st}\right]_0^T$$

$$= \lim_{T\to\infty}\left(-\frac{e^{-sT}}{s} + \frac{1}{s}\right) = \frac{1}{s}$$

$$\boxed{\mathcal{L}\{1\} = \frac{1}{s}, \qquad s > 0}$$

### Example 2 — $\mathcal{L}\{t\}$

Integration by parts with $u = t$, $dv = e^{-st}dt$:

$$\mathcal{L}\{t\} = \int_0^\infty t\,e^{-st}\,dt = \lim_{T\to\infty}\left(\left[-\frac{t}{s}e^{-st}\right]_0^T + \frac{1}{s}\int_0^T e^{-st}\,dt\right)$$

The boundary term $-\frac{T}{s}e^{-sT}\to 0$ for $s>0$. The remaining integral gives $\frac{1}{s}\cdot\frac{1}{s}$:

$$\boxed{\mathcal{L}\{t\} = \frac{1}{s^2}, \qquad s > 0}$$

### Example 3 — $\mathcal{L}\{\cos\omega t\}$

Using the shorthand $f(t)\big|_0^\infty = \lim_{T\to\infty}f(t)\big|_0^T$ and the integral table entry:

$$\int e^{ax}\cos bx\,dx = \frac{e^{ax}(b\sin bx + a\cos bx)}{a^2+b^2}$$

with $a = -s$, $b = \omega$:

$$\mathcal{L}\{\cos\omega t\} = \frac{e^{-st}(\omega\sin\omega t - s\cos\omega t)}{s^2+\omega^2}\bigg|_0^\infty = 0 - \frac{-s}{s^2+\omega^2}$$

$$\boxed{\mathcal{L}\{\cos\omega t\} = \frac{s}{s^2+\omega^2}, \qquad s > 0}$$

### Example 4 — $\mathcal{L}\{\sin\omega t\}$

Same approach with $\int e^{ax}\sin bx\,dx = \dfrac{e^{ax}(a\sin bx - b\cos bx)}{a^2+b^2}$:

$$\mathcal{L}\{\sin\omega t\} = \frac{e^{-st}(-s\sin\omega t - \omega\cos\omega t)}{s^2+\omega^2}\bigg|_0^\infty = 0 - \frac{-\omega}{s^2+\omega^2}$$

$$\boxed{\mathcal{L}\{\sin\omega t\} = \frac{\omega}{s^2+\omega^2}, \qquad s > 0}$$

### Example 5 — $\mathcal{L}\{e^{at}\}$

$$\mathcal{L}\{e^{at}\} = \int_0^\infty e^{at}e^{-st}\,dt = \int_0^\infty e^{(a-s)t}\,dt = \frac{1}{a-s}e^{(a-s)t}\bigg|_0^\infty = \frac{1}{s-a}$$

$$\boxed{\mathcal{L}\{e^{at}\} = \frac{1}{s-a}, \qquad s > a}$$

%%
The condition $s > a$ is essential — it is what makes $e^{(a-s)T}\to 0$ as $T\to\infty$. If $s \leq a$ the integral diverges.
%%

### Example 6 — Piecewise Function

For $f(t) = \begin{cases} 1 & 0 \leq t < 1 \\ 0 & 1 \leq t < 2 \\ 1 & 2 \leq t < 3 \\ 0 & 3 \leq t \end{cases}$:

$$\mathcal{L}\{f\} = \int_0^1 e^{-st}\,dt + \int_2^3 e^{-st}\,dt = \frac{1-e^{-s}}{s} + \frac{e^{-2s}-e^{-3s}}{s} = \frac{1-e^{-s}+e^{-2s}-e^{-3s}}{s}$$

%%
The linearity of the integral lets us split at the discontinuities. Each piece is just $\mathcal{L}\{1\}$ over a finite interval. This is the key — the Laplace transform absorbs the discontinuities into the algebra of $F(s)$ without any stitching.
%%

### Example 7 — The Sawtooth (Exercise)

For the infinite sawtooth $g(t) = t - n$ on $n \leq t < n+1$:

$$\mathcal{L}\{g\} = \sum_{n=0}^\infty \int_n^{n+1}(t-n)e^{-st}\,dt = \cdots = \frac{1-(s+1)e^{-s}}{s^2(1-e^{-s})}$$

The infinite sum collapses to a closed form via the geometric series. A single compact expression captures the infinitely-many-piece forcing function.

## A Table of Standard Transforms

| $f(t)$ | $F(s)$ | Condition |
|---|---|---|
| $1$ | $\dfrac{1}{s}$ | $s>0$ |
| $t^n$ | $\dfrac{n!}{s^{n+1}}$ | $s>0$ |
| $t^p$, $p>-1$ | $\dfrac{\Gamma(p+1)}{s^{p+1}}$ | $s>0$ |
| $e^{at}$ | $\dfrac{1}{s-a}$ | $s>a$ |
| $t^n e^{at}$ | $\dfrac{n!}{(s-a)^{n+1}}$ | $s>a$ |
| $\cos\omega t$ | $\dfrac{s}{s^2+\omega^2}$ | $s>0$ |
| $\sin\omega t$ | $\dfrac{\omega}{s^2+\omega^2}$ | $s>0$ |
| $e^{\lambda t}\cos\omega t$ | $\dfrac{s-\lambda}{(s-\lambda)^2+\omega^2}$ | $s>\lambda$ |
| $e^{\lambda t}\sin\omega t$ | $\dfrac{\omega}{(s-\lambda)^2+\omega^2}$ | $s>\lambda$ |
| $\cosh bt$ | $\dfrac{s}{s^2-b^2}$ | $s>\|b\|$ |
| $\sinh bt$ | $\dfrac{b}{s^2-b^2}$ | $s>\|b\|$ |
| $u(t-\tau)$ | $\dfrac{e^{-\tau s}}{s}$ | $s>0$ |
| $\delta(t-a)$ | $e^{-as}$ | $s>0$ |
| $u(t-\tau)f(t-\tau)$ | $e^{-\tau s}F(s)$ | — |
| $e^{at}f(t)$ | $F(s-a)$ | — |
| $\int_0^t f(\tau)g(t-\tau)\,d\tau$ | $F(s)\cdot G(s)$ | — |

## Useful Features of $\mathcal{L}$

### Feature (i) — Linearity

> [!definition] Linearity of $\mathcal{L}$
> If $\mathcal{L}\{f\}$ and $\mathcal{L}\{g\}$ are both defined for $s \geq s_0$, then for any scalars $a, b$:
> $$\mathcal{L}\{af + bg\} = a\mathcal{L}\{f\} + b\mathcal{L}\{g\}$$

**Proof:** linearity of the integral:

$$\mathcal{L}\{af+bg\} = \int_0^\infty (af(t)+bg(t))e^{-st}\,dt = a\int_0^\infty f(t)e^{-st}\,dt + b\int_0^\infty g(t)e^{-st}\,dt = a\mathcal{L}\{f\} + b\mathcal{L}\{g\}$$

### Feature (ii) — Transform of Derivative

> [!definition] Derivative Rule
> If $\mathcal{L}\{y\} = Y(s)$, then:
> $$\mathcal{L}\{y'\} = sY(s) - y(0)$$

**Proof:** integration by parts with $u = e^{-st}$, $dv = y'(t)dt$:

$$\int_0^\infty y'(t)e^{-st}\,dt = \Big[y(t)e^{-st}\Big]_0^\infty + s\int_0^\infty y(t)e^{-st}\,dt = -y(0) + sY(s)$$

Applying the rule twice:

$$\mathcal{L}\{y''\} = s\mathcal{L}\{y'\} - y'(0) = s(sY(s)-y(0)) - y'(0) = s^2Y(s) - sy(0) - y'(0)$$

> [!note] Why this is the key
> Both initial conditions $y(0)$ and $y'(0)$ enter automatically. The ODE becomes an algebraic equation with the IVP already encoded.

---

## Transforming an IVP to an Algebraic Equation

For the general second-order IVP:

$$ay'' + by' + cy = f(t), \qquad y(0) = y_0,\; y'(0) = y_0'$$

Apply $\mathcal{L}$ to both sides using linearity and the derivative rules:

$$a\mathcal{L}\{y''\} + b\mathcal{L}\{y'\} + c\mathcal{L}\{y\} = F(s)$$

$$a(s^2Y - sy_0 - y_0') + b(sY - y_0) + cY = F(s)$$

Collect $Y$ terms:

$$\underbrace{(as^2 + bs + c)}_{P(s)}Y(s) = F(s) + \underbrace{(as + b)y_0 + ay_0'}_{\text{ICs}}$$

$$\boxed{Y(s) = \frac{F(s) + (as+b)y_0 + ay_0'}{as^2+bs+c}}$$

This is now **algebra**. No differential equations remain. Then invert $Y(s)$ using partial fractions and the table.

---

## Worked Example

Solve:

$$y'' + 2y' + 5y = \cos t, \qquad y(0) = 1,\; y'(0) = 0$$

**Step (i) — Transform both sides:**

$$\mathcal{L}\{y''\} + 2\mathcal{L}\{y'\} + 5\mathcal{L}\{y\} = \mathcal{L}\{\cos t\}$$

$$(s^2Y - s\cdot 1 - 0) + 2(sY - 1) + 5Y = \frac{s}{s^2+1}$$

$$(s^2 + 2s + 5)Y - s - 2 = \frac{s}{s^2+1}$$

**Step (ii) — Solve for $Y(s)$:**

$$Y(s) = \frac{s}{(s^2+1)(s^2+2s+5)} + \frac{s+2}{s^2+2s+5}$$

**Step (iii) — Complete the square in denominator:**

$$s^2 + 2s + 5 = (s+1)^2 + 4 \implies \lambda = -1,\; \omega = 2$$

**Step (iv) — Partial fractions on the first term:**

$$\frac{s}{(s^2+1)(s^2+2s+5)} = \frac{As+B}{s^2+1} + \frac{Cs+D}{s^2+2s+5}$$

Matching coefficients: $A+C=0$, $2A+B+D=0$, $5A+2B+C=1$, $5B+D=0$.

Solving: $A=-\frac{1}{5}$, $B=\frac{2}{17}$... (algebra intensive — see lecture for full values).

**Step (v) — Invert term by term using the table:**

$$\frac{s+2}{s^2+2s+5} = \frac{(s+1)+1}{(s+1)^2+4} = \frac{s+1}{(s+1)^2+4} + \frac{1}{2}\cdot\frac{2}{(s+1)^2+4}$$

From the table: $\mathcal{L}^{-1}\!\left\{\frac{s-\lambda}{(s-\lambda)^2+\omega^2}\right\} = e^{\lambda t}\cos\omega t$ and $\mathcal{L}^{-1}\!\left\{\frac{\omega}{(s-\lambda)^2+\omega^2}\right\} = e^{\lambda t}\sin\omega t$.

With $\lambda = -1$, $\omega = 2$:

$$\mathcal{L}^{-1}\!\left\{\frac{s+2}{s^2+2s+5}\right\} = e^{-t}\cos 2t + \frac{1}{2}e^{-t}\sin 2t$$

The remaining partial fraction term gives contributions from $\cos t$ and $\sin t$. The full solution after combining all terms is:

$$y = y_p + e^{-t}\!\left(\cos 2t + \frac{1}{2}\sin 2t\right)$$

where $y_p$ involves $\cos t$ and $\sin t$ from the forcing.

%%
The inversion step is where the whole method pays off. Each term in the partial fractions decomposition matches exactly one entry in the Laplace table, and the answer is assembled by reading off the inverse transforms. No differential equation is ever solved directly.
%%

## Technical Constraints — When Does $\mathcal{L}\{f\}$ Exist?

The integral $\int_0^\infty f(t)e^{-st}\,dt$ converges when $f$ satisfies three conditions:

> [!definition] Sufficient Conditions
> $\mathcal{L}\{f\}$ is defined for $s \geq s_0$ if $f$ is:
> 1. **Piecewise continuous** on $[0,\infty)$ — finitely many jump discontinuities on any finite interval, with finite one-sided limits at each jump
> 2. **Bounded** on $[0,T]$ for every finite $T > 0$
> 3. **Of exponential type** on $[0,\infty)$

> [!definition] Exponential Type
> $f(t)$ is of **exponential type** on $[0,\infty)$ if there exist positive constants $M$ and $T_0$ such that:
> $$|f(t)| \leq Me^{\lambda t} \quad \text{for all } t > T_0$$
> for some $\lambda$. This means $f$ does not grow faster than some exponential.

%%
Condition 3 is what requires $s > \lambda$ in the table entries. The $e^{-st}$ damping factor in the transform must beat the growth of $f(t)$. A function like $e^{t^2}$ is not of exponential type — it grows faster than any exponential, and its Laplace transform does not exist.

Condition 1 is why discontinuous forcing functions like the sawtooth are fine — piecewise continuous allows jump discontinuities, and the Laplace transform integrates across them without any stitching required.
%%

> [!warning] What fails
> $f(t) = e^{t^2}$ — not of exponential type, no Laplace transform.
> $f(t) = 1/t$ near $t=0$ — not bounded, no Laplace transform.
> A function with infinitely many jumps on a finite interval — not piecewise continuous.

---

## The Payoff

The Laplace transform converts:

$$\underbrace{\text{ODE with ICs}}_{\text{calculus problem}} \xrightarrow{\mathcal{L}} \underbrace{\text{algebraic equation for }Y(s)}_{\text{algebra problem}} \xrightarrow{\text{solve}} Y(s) \xrightarrow{\mathcal{L}^{-1}} \underbrace{y(t)}_{\text{solution}}$$

Discontinuous forcing — which requires stitching across intervals in direct methods — is absorbed into $F(s)$ and handled algebraically. The more complex the forcing, the greater the advantage.
