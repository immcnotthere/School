# Falling Object with Different Initial Velocities

Apply $v(0)=50$ and $v(0)=100$ to $v(t)=49+Ce^{-t/5}$ to get $v(t)=49+e^{-t/5}$ and $v(t)=49+51e^{-t/5}$ respectively.
