# Nested Uniform Expectation via LIE

Find $E[Y]$ for $Y\mid X=x\sim\text{Unif}(x,1)$, $X\sim\text{Unif}(0,1)$, by computing $E[Y\mid X]=(X+1)/2$ and applying LIE.
