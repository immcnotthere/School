# Expected Values of Common Distributions

Standard results: $\mathbb{E}[X]=p$ for Bernoulli(p), $\lambda$ for Poisson($\lambda$), $(a+b)/2$ for Uniform(a,b), $1/\lambda$ for Exponential($\lambda$), and $np$ for Binomial(n,p).
