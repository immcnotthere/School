# Standard Normal CDF (Φ)

$\Phi(x)=P(Z\le x)$ for standard Normal $Z$, evaluated numerically; it satisfies $\Phi(-x)=1-\Phi(x)$, so $P(-k\le Z\le k)=2\Phi(k)-1$.
