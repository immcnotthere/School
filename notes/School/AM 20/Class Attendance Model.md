# Class Attendance Model

Solve $\frac{dp}{dt}=\frac{1}{2}p-100$ with $p(0)=170$ to get $p(t)=200-30e^{t/2}$; find $p(3)\approx65.55$ students and the time attendance hits 0, $t\approx3.794$ months.
